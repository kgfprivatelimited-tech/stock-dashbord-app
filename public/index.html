🔧 Admin Panel Features
📊 Overview (Dashboard)
Dashboard Total users, active users, pending devices, pending renewals — sab ek jagah dikhta hai. Quick stats cards se turant status samajh aata hai.
➕ Create User
Create Naya user banao — Username, Email, Password, Full Name, Category (Silver/Gold/Diamond/Premium), Subscription Days, Payment details, Telegram Chat ID, WhatsApp Number.
👥 All Users
Users Saare users dikhenge — search karo, filter karo. Har user ke baju icons: ✏️ Edit, 📚 Class ON/OFF toggle, 🚫 Block / ✅ Renew, 🗑️ Delete. Click on user row → full edit form khulega.
Bulk Checkboxes select karke bulk category change karo. Export CSV bhi available hai.
📚 Class Access Har user ke baju 📚 ON/OFF toggle hai. ON = user videos dekh sakta hai. OFF = user ko "Contact Admin" dikhega.
📢 Broadcast
Message Text message likho, color choose karo, users select karo (sab ya category ya search karke). Telegram bhejo ☑️, WhatsApp link generate karo ☑️. Message user ke dashboard pe banner dikhata hai + bell notification + browser push + sound + vibration.
🎁 Offers
Offer Naya offer banao — title, description, bonus days, promo code, max uses. Target users select karo. Offer create karte hi selected users ko notification jaata hai.
⏰ Scheduled Messages
Schedule Message likho, future date/time set karo. Server automatically us time pe message bhejega selected users ko.
💳 Reminders
Renewal Jin users ka subscription 1-3 din me expire ho raha hai, unhe automatic reminder jaata hai (har 6 ghante). Manual "Send Reminders" button se abhi turant bhej sakte ho.
📋 Renewal Requests
Renew User ne Renew pe click kiya → UPI payment kiya → admin ko request dikhti hai. Plan, amount, days, txn ID sab dikhta hai. Approve karo → user ki expiry badh jaati hai. Reject karo → request hata di.
🎉 Holiday Banners
Banner Festival/holiday ke liye banner banao — image upload (URL ya base64), title, message, color, schedule. Desktop/Mobile toggle. Users ko banner dikhega.
📚 Trading Class
Class Modules banao (title, description, order, thumbnail). Videos add karo (YouTube, Google Drive, Mega, Direct MP4, OneDrive, Embed). Access control: All users / Category based / Specific users. Admin approval ke bina user video nahi dekh sakta.
🎛️ Dashboard Settings
Config Dashboard ke sections toggle karo (Indices, Heatmap, Tips, Signals etc.). Stock tips configuration. Sector stocks list manage karo.
⚙️ Disclaimer
Legal Disclaimer text, background color, text color, speed, font size — sab customize karo. Preview dikhta hai.
🔧 Maintenance Mode
Maintenance ON karo → sirf admin access kar sakta hai, users ko maintenance page dikhta hai. Schedule bhi set kar sakte ho (auto ON/OFF). Custom message likho. Daily maintenance window bhi set kar sakte ho (raat ko automatic).
🔐 Change Password
Security Admin password change karo. Users ke passwords bhi reset kar sakte ho.
🔑 API Keys
API Upstox API key + access token manage karo. Google OAuth credentials. Telegram bot token.
📊 Heatmap Stocks
Stocks Har sector me kaunse stocks dikhne chahiye wo configure karo. Add/Remove/Reset defaults.
🎯 Tip Performance
Analytics Kitne tips diye, kitne target hit hue, kitne SL hit hue — sab stats.
🕐 Recent Activity + 🔑 Login History
Logs Kaunne kya kiya — login, logout, broadcast, user create/delete, device approve. Timestamps ke saath.
👤 User Panel Features
📊 Dashboard
Home Login ke baad dashboard dikhta hai — Nifty, Sensex, Bank Nifty live indices. Market status (Open/Close). Subscription badge with days left. Highlighted users ka naam golden hota hai.
📈 Indices (Live)
Live Nifty 50, Sensex, Bank Nifty — real-time Upstox V3 API se. Market hours me 2 sec, close hone pe 30 sec. Har tick update hota hai.
🗺️ Heatmap
Visual Sector-wise heatmap — red/green colors se pata chalta hai kaun sector upar hai kaun neeche. Stocks hover karke live price dekho.
📊 Stock Tips
BUYSELL Admin ne diye tips yahan dikhte hain — Entry, Target, SL, Note. Active, Target Done ✅, SL Hit ❌ status.
⚡ Signals
Signal EMA/RSI based automatic buy/sell signals. RSI overbought/oversold, EMA crossover detection.
📱 Bottom Navigation Bar
Nav Profile 👤 — Apna profile dekho, name/email/password change, social verification (Google/Telegram), DOB, device info.
📚 Class Trading classes — modules dikhte hain. Admin ne approve kiya toh videos play hongi. Nahi toh "Contact Admin" dikhega.
🔄 Renew Self-renewal — plan choose karo, UPI pe payment karo, txn ID dalo. Admin approve karega.
📱 Telegram Bear Fighter Telegram group/channel se judo.
💬 WhatsApp Bear Fighter WhatsApp group se judo.
🔔 Alerts Notification bell — broadcast messages, stock tips, offers — sab yahan dikhta hai. Browser push notification bhi aata hai.
🚪 Logout Logout karo.
📝 Registration (New Users)
Register /register pe jaake form bharo — name, email, phone, category choose, UPI payment. Admin approve karega.
🔐 Security Features
Device Lock Sirf 1 device allowed hai. Naya device use karo toh admin approval lagegi. Approve hone pe purana device hata diya jaata hai.
Screenshot Block Screenshot/Screen recording disable hai. Right-click, Ctrl+U, Ctrl+S sab blocked hai.
Social Verification Google ya Telegram link karo profile se. Dono link ho jaayein toh blue tick ✅ milta hai.

⚡ Background Jobs (Server pe automatic chalte hain)
2 sec Stock Data Refresh — Market hours me Upstox V3 API se live stock data fetch hota hai (indices, gainers/losers, heatmap). 15 sec cache TTL.
15 sec Stock Background Refresh — `refreshStocksBackground()` — Market close hone pe bhi background me data ready rakhta hai.
1 min Scheduled Messages — Jo messages schedule kiye gaye hain, unhe time aane pe automatically bhejta hai.
6 hours Payment Reminders — Jin users ka subscription 1-3 din me expire ho raha hai, unhe automatic Telegram + dashboard reminder bhejta hai.
1 min Maintenance Check — Scheduled maintenance window check karta hai. Time aane pe auto ON/OFF. Users ko notification bhejta hai.
1 min Signal History Save — Trading signals ka history save hota hai JSON file me.

💡 Quick Tips
Tip Deploy: GitHub pe push karo → Render.com pe auto-deploy hota hai.
Tip Upstox Token: Access token expire hota hai (~1 year). .env me naya token dalo.
Tip MongoDB: Agar Atlas disconnect ho jaye toh JSON files se data load hota hai (fallback).
Tip Backup: users.json + settings.json + .env — ye 3 files hamesha backup rakho.
Tip Device Lock: Sirf 1 device per user. Switch = fresh admin approval.
Tip Class Access: Admin ko manually 📚 ON karna padta hai per user.
Tip Browser Notifications: User ko "Allow" karna padta hai jab prompt aaye. Bina allow ke push nahi aayega.
Tip Service Worker: HTML pages kabhi cache nahi hoti (v8). Sirf static assets cache hoti hain.
Tip Admin Password: Default: bearfighter@admin. Admin panel me jaake change karo.
Tip UPI Payment: User ne payment ki → Renew pe click kiya → admin ko request aayi → Approve/Reject.
