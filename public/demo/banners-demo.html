🇮🇳 Independence Day Banner Demos

15 August 2026 ke liye 6 ready-made banners · Bearfighter.in dashboard ke liye · Desktop + Mobile preview
Admin panel me kaise use kare:
1. Dashboard → Admin Panel → 🎉 Holiday Banners → + Create New Banner.
2. Upar wala JSON copy karke fields me values daalo — Image URL me /banners/demo-X-xxx.svg (ya full URL) paste karo, Show Title/Show Message uncheck karo (text image ke andar hai).
3. Start Date: 2026-08-10, End Date: 2026-08-17, Height: 300px, Position: afterDisclaimer.
4. Save → Dashboard par banner turant dikhega. Mobile par 180px height pe image ka center part dikhta hai (text center me rakha hai, safe hai).

Note: Banner JSON me showTitle:false / showMessage:false rakha hai kyunki design ke andar text baked hai. Agar tumhe alag text chahiye to Show Title on karke title likh do (image ke saath text overlay ni dikhega — image hi poora banner hai).
